# Library Management System

![Java](https://img.shields.io/badge/Java-17-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

Проект представляет собой систему управления библиотекой, написанную на Java. Этот проект позволяет управлять книгами, читателями и выдачей книг в библиотеке.

## Основные функции

- **Управление книгами**: Добавление, удаление, редактирование и поиск книг.
- **Управление читателями**: Регистрация новых читателей, обновление информации о существующих читателях.
- **Выдача книг**: Возможность выдачи книг читателям и возврата книг в библиотеку.
- **Отчеты**: Генерация отчетов по выданным книгам, просроченным возвратам и т.д.

## Установка и запуск

1. **Клонируйте репозиторий**:
    ```bash
   git clone https://github.com/SirRamzi/library.git
   cd library 
   ```

2. **Соберите проект**:

    Убедитесь, что у вас установлен JDK 17 или выше. Затем выполните:
   ```bash
   ./mvnw clean install
   ```

3. **Запустите приложение**:
   ```bash
    ./mvnw spring-boot:run
   ```

4. **Откройте в браузере**:
   
    Приложение будет доступно по адресу: http://localhost:8080.

## Структура проекта

- `src/main/java` - Исходный код на Java.
    - `com.sirramzi.library` - Основной пакет.
        - `controller` - Контроллеры для обработки HTTP запросов.
        - `model` - Модели данных (книги, читатели и т.д.).
        - `repository` - Репозитории для работы с базой данных.
        - `service` - Бизнес-логика приложения.
- `src/main/resources` - Ресурсы приложения (конфигурации, статические файлы и т.д.).
- `src/test` - Тесты для приложения.

## Используемые технологии

- **Java 17** - Основной язык программирования.
- **Spring Boot** - Фреймворк для создания приложения.
- **Hibernate** - ORM для работы с базой данных.
- **PostgreSQL** - База данных для хранения информации.
- **Maven** - Управление зависимостями и сборка проекта.
